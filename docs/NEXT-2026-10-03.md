First establish its stage-1 Qwen baseline and correctness gates on MI300X.
Complete CPU acceptance before a GPU session. Passing CPU checks does not establish hardware correctness or a performance baseline.
After those prerequisites, candidate 1 is first among the research experiments below.
ETX must prove a fusion benefit with the same production kernels, plus a win against the best real system.
The current DSL result proves a narrower claim.

PhiMoE passes 32/32 tokens, the DSL check, and the coverage check at context 1024 and batch 1.
The coverage check permits one tie among 1055 positions.
Its wall median is 6.466 ms/token against vLLM default at 11.057 and AITER at 11.360.

Older plans contain hypotheses, not current evidence. In particular, round33 rejects whole-layer batch 2 at 7.483 versus replicated 6.901 ms/step.

## Ranked candidates

### 1. Isolate the PhiMoE fusion benefit and the vLLM gap

**Unknown.** Does fusion explain any material part of the 4.591 ms system advantage?
First compare identical DSL tiles through the megakernel and a HIP graph, with debug synchronization off.
Record five interleaved pairs, plus vLLM default and AITER controls. Record both wall time and device span.
Capture a decode trace only if no reusable trace exists. Separate host work, kernel work, and gaps.
Count active weight and KV bytes from the manifest. Divide bytes by 4.3 TB/s for an estimated bandwidth floor.
No verified PhiMoE byte count or gap ceiling exists in the inspected archive.

**Go/no-go.** Require all correctness gates, a positive paired gain in every pair, and a median gain above 2%.
Also require the gain to exceed twice the paired run spread. Use relative gain for both checks.
Otherwise report no established fusion benefit.
Success validates fusion for these tiles. Failure leaves the system advantage unexplained by a demonstrated fusion benefit.
Neither outcome proves the all-imported claim. Trace evidence determines whether candidate 2 has a recoverable budget.

**Estimate.** One GPU, 45–60 minutes active, 1–1.5 hours allocated, $2.99–$4.49.
**Local first.** Audit graph equivalence and timer scope. Prepare the byte ledger, paired-result parser, and bounded session job.
Reuse round48 goldens and logs. Complete the common preflight below.

### 2. Test a safe acquire for imported kernels

**Unknown.** Can a compiler transformation preserve kernel semantics and remove the whole-L2 acquire cost?
This directly addresses the original claim. It must not become another tile rewrite.
Audit activation aliasing, cache modifiers, and cross-XCD communication before any GPU build.
Use one producer/consumer pair from the actual imported path for the first microbenchmark.
The known kernel boundary is 1.61 us. Whole-card barriers and uncached allocations alone already failed.

**Go/no-go.** Require zero stale reads over at least 100 million transfers and byte-identical imported outputs.
Require at least 0.35 ms/token of projected savings from existing phase counts and the new measured pair cost.
That threshold exceeds the measured 0.284 ms fusion penalty. Otherwise stop before a full model build.
Success justifies one full-model A/B with both baselines. Failure closes this transformation, not all future fusion designs.

**Estimate.** One GPU, 10–20 minutes for the probe. At most 2 hours allocated with the conditional model test, $5.98 maximum.
**Local first.** Specify the memory contract, prove or check event order, inspect emitted IR, and reject unknown alias patterns.
Complete the common preflight. Do not rent hardware if the contract remains unresolved.

### 3. Test correctness under concurrent execution

**Unknown.** Do other folds have the race that isolated operator checks missed in round48?
Test real-weight folds under full occupancy and compare complete outputs, not only argmax tokens.
Coverage alone cannot detect output holes above all reference argmax positions.

**Go/no-go.** Require zero values beyond the existing 2 bf16 ulp gate over 1000 repetitions per selected shape.
Require a deliberately missing barrier or output hole to fail the new check.
Success strengthens the gate before more models. Failure blocks performance claims for the affected path until repair.
This is a correctness experiment, so no bandwidth or speedup target applies.

**Estimate.** One GPU, 15–30 minutes active, 0.5–1 hour allocated, $1.50–$2.99.
**Local first.** Inventory all shared-LDS reads, derive coverage assertions, and prepare negative tests for Qwen, Mixtral, and PhiMoE.
Use sparse synthetic weights where possible. Complete the common preflight.
