## Two independent validity inputs

After fresh correctness certification, tranche A runs the unchanged `kept`
original and the `stamps` executable with all stamping OFF, each with
`--repeat 5`. These controls have neither `ETX_INBODY_RAW` nor
`ETX_HOUR_TRACE_STEP`; all diagnostic pointers stay null. `ETX_INBODY_LOADS=0`
also explicitly disables load stamps. This differs from the existing
`stamps_load_off.bin` snapshot, which retains gap/body stamps to measure
load-stamp ON-minus-OFF perturbation. That single snapshot supplies the first
input, not the run-spread input.

Each control requires five full free-running 32/32 token matches and five
report-enabled `INBODY-RUN` observations. The registered basis from
`docs/INBODY-INSTRUMENT-2026-10-11.md` is five per-repeat host-wall medians,
with noninterleaved arm distributions. The OFF check is:

```python
delta = st.median(off)-st.median(original)
spread = max(max(original)-min(original), max(off)-min(off))
within = abs(delta) <= spread
```

Full logs are `A_control_original.log` and `A_control_stamps_OFF.log`.
`A_original_off.json` and `ORIGINAL-OFF-CONTROL` retain both sample
distributions, their medians/spreads, the movement and the larger spread bar.
The analyzer receives this evidence file and recomputes the boolean from
the sample populations before passing it to `stamp_perturbation`. Missing,
partial, nonfinite, failed or timed-out controls retain a named reason in
`stamp_perturbation.original_off_control` in the S1 row. They never supply
`True`. An OFF movement outside the spread supplies `False` and also refuses
G. The original tranche deadline bounds these new control measurements;
there is no extra budget and no shortened population when time runs out.

## Existing G definition, now visible

The deciding code in `gap_atom_prices` remains:

```python
G_ms=sum(a['above_floor_ms'] for a in atoms.values() if a['counted'])
```

`first_stop` still compares that `G_ms` to 0.088 after both validity checks
and fresh kept correctness. It does not substitute the setup atom. Both the
`A.stop` row and the `S1-G` log name the figure as
`sum of counted named above-floor atoms`, quote the expression above, list
the counted atom names and retain `setup_atom_ms` and
`named_above_floor_sum_ms` even when validity masks G. `S1-G.gate_compared_ms`
is exactly the value compared by the gate (null when refused).

The supplied 2026-10-12 machine figures are **0.09274 ms setup alone** and
**0.356727 ms for the three counted atoms** before validity masking. This
change preserves the existing sum, prints both figures, and sets
`G_figure_disagreement=true` with `OWNER RULING NEEDED`. It does not resolve
the registered wording's ambiguity on the owner's behalf. These are upper
opportunity estimates, not certified removable savings; CPU fixtures for
the two non-setup shares are synthetic, not additional machine evidence.
